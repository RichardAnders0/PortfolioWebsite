# Richard Anders | Portfolio

A responsive one-page portfolio for Richard Anders, a Computer/Information Technology Administration and Management student at Florida State College at Jacksonville (FSCJ).

**Live site:** https://richardanders0.github.io/PortfolioWebsite/
**Repository:** https://github.com/RichardAnders0/PortfolioWebsite

## About the project

The page covers my background, skills (hardware, systems and software, security and networking, support), education, and contact info. The skills are shown as a stack of layers with hardware at the base, and that idea carries from the hero into the skills section.

## Built with

- HTML5
- CSS3 (custom properties, flexbox, grid, media queries)
- Vanilla JavaScript (mobile menu toggle)
- Google Fonts: Bricolage Grotesque and IBM Plex Sans

## Project structure

```
index.html
css/styles.css
js/main.js
README.md
```

## UI/UX notes

- Two typefaces: Bricolage Grotesque for headings, IBM Plex Sans for body text.
- A small palette: navy ink, one blue accent, and neutrals, chosen for readable contrast.
- Generous, consistent spacing, with body text kept under about 65 characters per line.
- Responsive breakpoints at 900px and 680px, with a collapsing menu on mobile.
- Visible keyboard focus, a skip link, and reduced-motion support.

## Run locally

1. Clone the repo: `git clone https://github.com/RichardAnders0/PortfolioWebsite.git`
2. Open `index.html` in a browser.

## Deployment steps (GitHub Pages)

1. Push the project to a public GitHub repository, with `index.html` at the root.
2. In the repository, open **Settings**, then **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the **main** branch and the **/ (root)** folder, then click **Save**.
5. Wait a minute or two, then open the live URL shown at the top of the Pages screen.
6. Click through every link and check the site on a phone.
